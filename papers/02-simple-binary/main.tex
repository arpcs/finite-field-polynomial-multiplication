\begin{abstract}
We give an exact algorithm for multiplication in $\F_2[X]$ with
$O(n\log(n+2))$ bit complexity, using the arbitrary-width tape
interchange theorem of OpenAI (2026) as an external algorithmic input.
The construction uses an explicit tower of
ternary cyclotomic fields, arbitrary prefixes of an $\F_4$ flag, sparse
polynomial-radix extraction, and a shared Taylor layer for sibling
cosets. Local scalar actions are charged by the child field degree,
even though the ambient coefficient field stays fixed throughout the
recursion. Elementary Karatsuba multiplication suffices. A residue
pairing reconstructs the product from one affine evaluation grid and
its three field conjugates; its ordinary binary transpose is explicit.
We prove a uniform binary tensor bound with a fixed strict saving in
tensor height from a finite ternary phase network, dirty address
selectors and an explicit word over $\F_{16}$. This supplies the
Pascal transforms required by the multiplication reduction. All costs
refer to one deterministic finite-alphabet machine with a fixed finite
number of tapes, including setup, movement and cleanup. The external
input is a routing theorem, rather than an integer-multiplication
oracle or a hypothesis on primes. Bounded C++ witnesses
check evaluation/product/decoder algebra and ordinary adjoints on
finite instances; they do not implement the asymptotically fast tensor machine.
The same asymptotic bound holds for the ordinary binary transpose of
multiplication by either fixed operand.
\end{abstract}
