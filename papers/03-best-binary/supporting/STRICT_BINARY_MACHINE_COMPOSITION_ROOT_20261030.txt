==============================================================

Conventions
-----------
All logarithms in bounds here are binary, rounded up when used as integer
parameters. Fix a finite alphabet, fixed tape families, and ordinary
binary shape descriptors. A stream boundary means a complete array in
lexicographic order on its CURRENT named coordinates. An address is its
position, not a key carried permanently with each payload record.
Scratch used in a recursive family is restored by that family's call
protocol, and no caller reads its payload while a callee is active.

I. Freeze a polynomial before enlarging the word
----------------------------------------------
The generic controlled compiler explicitly retains a per-current-record
coefficient-generation bound G(R,L), including address/gauge, all target
settings, cleanup and returns. Its cost is
O((MD L^gamma+M G(R,L)) polylog L). The usual kernel tariff needs
G=O(D); an arbitrary polynomial degree is not paid by Q^64 automatically.
The concrete CRT generator below has degree12, so the frozen exponent64
is sufficient for this application. Current full derivation:
binary_strict_tape_candidate_20261030/
RAGGED_PARTITION_AND_CONTROLLED_METADATA_ROOT_20261030.txt.

Let R bound every native radix and let L bound the total native address
width and number of axes. Set Q=R+L+2. Use the following deliberately
inefficient but concrete coefficient generator for CRT routing.

1. Decode a scanned flat L-bit address by schoolbook division into its
   native digits. Decode each control gauge by at most ceil(log R)
   applications of the formulas
     S_n(x)=2(x mod(n/2))+floor(x/(n/2)),
     S_n^-1(x)=floor(x/2)+(n/2)(x mod2).
   Thus no modular inverse oracle or table indexed in unit time is used.
2. For each target axis, inspect its node's left controls. If a dummy is
   present, use the identity. Otherwise compute x_A by the CRT sum
     x_A = sum_j c_j (P_A/p_j) ((P_A/p_j)^-1 mod p_j) mod P_A.
   The products and inverses involving only node primes are public
   setup. Each variable CRT sum and modular affine table is produced
   with schoolbook integer arithmetic on O(L)-bit words. Generate all
   n_i values of the requested affine permutation, fixing its dummy.
   To generate an inverse, scan the forward table for each image value.
3. For an n-wire table, store records (packet,input pair,output pair,
   color,visited). The total list at one level has O(n) entries. For
   each as-yet-unvisited edge, find its next incident edge by scanning
   the list. Follow the cycle/path, marking by rewriting the list.
   A path starts at the singleton, with its forced endpoint color;
   a cycle starts at its least unvisited edge with color zero.
   Obtain E_in,E_out and the next child table by sequential full-list
   lookup for each of the n packets. Store the ragged interval list
   in [all even fragments][all odd fragments] order. Repeat at most
   ceil(log n) levels; completed singleton levels have no switches.
   For each setwise-invariant parent[a,b), fragments are exactly
   [ceil(a/2),ceil(b/2)) and
   [n/2+floor(a/2),n/2+floor(b/2)).
   They partition the same n-wire set in those two ordered halves.
   Topology is independent of the permutation and control tuple; only
   switch colors depend on it. Recurse once on the whole residual
   table/updated partition, keeping the same global shuffle at every level.
4. Select the requested level, sublayer, pair and endpoint by full
   sequential scans of these lists. Read its fixed eight-H/F4 table.
   Multiply the at-most-L target factors in F4. Output that ONE scalar
   coefficient and erase/reuse the local variable tables.

Here is an intentionally loose finite-tape bound, to fix the degree
rather than hide it in an unspecified polynomial. At most Q axes and Q
levels are visited. All the route records for one control tuple occupy
O(Q^5) bits: at most Q axes times Q levels times Q packets, with at most
O(Q^2) bits per overallocated record. Even allowing Q^6 elementary
list lookups/updates across these loops, replacing each by an entire
O(Q^5)-bit scan costs O(Q^11). Schoolbook arithmetic, address parsing,
CRT sums, table inversions and archive selection are bounded by O(Q^12)
with these same overallocations. Rewinds and erasures multiply this by
a fixed constant. The algorithm never enumerates control tuples, only
the one tuple decoded from the current record address.

Fix ONCE
     P1(R,L)=(R+L+2)^64.
For all sufficiently large Q this dominates the fixed constant times
Q^12 just derived, plus the address-counter, copying, gauge and scalar
selection costs. The bounded remaining Q range has a fixed finite direct
branch. Neither the exponent 64 nor the generator changes with N, tree
depth, control tuple, or payload. The table size can also be bounded by
P1. This is a computable uniform choice, not growing advice.

For each scanned record, park its D bits once on a local tape, compute
the coefficient on disjoint metadata tapes, apply its fixed F4 binary
map in a linear pass, and erase/rewind the parked interval. The cost is
O(D+P1). Under D>=P1 it is O(D). The main payload head waits at this
record boundary during metadata generation; it does not rewind the
whole array. Advancing the public address counter and copying it into
the generator is included in P1. Thus a scalar stage costs O(MD), with
no uncharged RAM access and no all-control table of size M*P1.

This P1 is for controlled CRT ROUTING, not for every small algebraic
setup routine. Fourier scalar constants may cost polynomial(D,R,L) to
prepare once; per-record multiplication by such a scalar is separately
charged as M_old(D), as in section V.

II. Width and native-shape compatibility
---------------------------------------
The host is constructed from the ordinary input length; it is not advice.
If needed, count/copy the end-marked coefficient lists in O(n) time.
At fixed p=2, apply HvdH Proposition3.4 to target2n, obtaining
2n<N<4n, its ordered prime tuple and attached lambda data in
2^O((loglog n)^2) bit time. Proposition3.8 supplies alpha, Phi_alpha
and principalK=N/q0 root rho in2^O((loglog N)^4) bit time.
Both are N^o(1) on the source's fixed-finite-tape model. Main now
states this imported initialization as a separate lemma.

Factor and root certificates can be checked in the same budget:
trial-divide the factors<=R0, verify their productN, and use
rho^K=1 and gcd(rho^(K/q_i)-1,Phi_alpha)=1 for all known q_i|K.
Squarefreeness makes the gcd condition enforce exact orderK in EVERY
field component, hence principal character sums. Polynomial(alpha,R0,L0)
schoolbook setup suffices; no new full multiplier is used. All emitted
objects are ordinary binary words on fixed tapes. The bounded initial
input range uses the direct branch. This initial setup is included
in the N^o(1) term separately from later word enlargement/tables.

Let N be the unconditional 2-admissible length, and L0=ceil(log N).
Let ell=ceil(log L0), choose the computable upper bound R0=2^(ell^2),
and R=R0+1. The original remaining primes satisfy
     L0^3 < p_i <= R0.
The author's selected alpha has at most O(ell^2) prime factors, so
     log alpha=O(ell^4),
     -log(phi(alpha)/alpha)=O(ell^2/L0^3).
These are properties of its actual construction, stronger than just
phi(alpha)/alpha>1-1/L0. Only the stronger estimate justifies preserving
the density after adding factors.

Use the uniform address bound L0+2 in P1, before choosing extra factors.
Append unused prime factors of N to alpha until
     D'=phi(alpha') >= (R0+L0+5)^64.
Let J=alpha'/alpha. Each new factor multiplies D by p-1>L0^2 for large
L0. The number added is at most
     1+ceil(64 log(R0+L0+5)/(2 log L0)) = O(ell).
Choose factors in their given deterministic order, and stop at the first
crossing. There are enough: log alpha'=O(ell^4) whereas log N~L0 and
each unused prime has log p<=ell^2. The previous factor count excludes
only O(ell^2) primes, while N has at least L0/ell^2 of them.

The first-crossing rule gives D'<(R0-1)*(R0+L0+5)^64 unless D already
exceeded the threshold. Consequently log D'=O(ell^4), including that
initial-D case. Furthermore
     -log(phi(alpha')/alpha')=O((ell^2+ell)/L0^3),
so phi(alpha')/alpha'>1-1/L0 for sufficiently large L0. Put m'=N/alpha'.
Then m'D'=N phi(alpha')/alpha'=Theta(N).

Root lift is an actual quotient homomorphism. With old variable Y and
new variable U, send Y to U^J modulo Phi_alpha'(U). Since alpha,J are
coprime and squarefree, a primitive alpha'-root raised to J has order
alpha; hence Phi_alpha' divides Phi_alpha(U^J) in F2[U]. Unital ring
homomorphisms preserve the old root's character-sum identities. If w
is the image of an old principal m-th root (m=N/alpha), w^J is principal
of order m'=m/J: an m-th character sum for exponent Jj is J times the
m'-th character sum, and J is odd, hence a unit in characteristic two.
The source gives rho of principal order K=N/q0, where the distinguished
prime q0 divides alpha. The old m-root is exactly rho^(alpha/q0),
since m=K/(alpha/q0); no principal N-root is assumed.
All constants are prepared once in
polynomial(alpha',R0,L0)=2^O(ell^4)=N^o(1) bit time.

Pad each remaining p_i to n_i=p_i+1. With M=product n_i,
     M/m'=product(1+1/p_i)<=exp(t/L0^3)=1+O(L0^-2).
Since alpha'>=D'>L0^64, 2M<N for large L0, so
     L=ceil(log(2M))<=L0.
Thus the canonical/native hypotheses L^3<=n_i<=R and D'>=P1(R,L)
hold simultaneously. Also L=L0-O(ell^4)=Theta(L0), log R=O(ell^2).
This checks the rounded-width hypothesis instead of identifying two
slightly different logarithms without an inequality.

III. Stream order and controlled coefficients at EVERY outer boundary
----------------------------------------------------------------------
Fix a target set T and control set C for one CRT tree level. At entry,
position x=(x_i) has an ordinary D'-bit payload in native lexicographic
order. Let e be the signed count of completed full forward minus inverse
shuffle slots. It is a public scalar, initially zero. At each completed
outer slot the stream is again native lexicographic order, and a stored
record at address x occupies THAT address; no hidden old key determines
its scalar coefficient.

For a fixed original logical control c, the invariant subspace is
supported at the CURRENT physical control address q_e(c)=S_C^e(c).
Within that fiber, the target coordinates have undergone precisely the
prefix of their ragged-network word generated for pi_i(c). This is an
invariant for arbitrary payloads, by linearity, not just packet labels.

At a scalar slot reset a native lexicographic address counter, decode
the CURRENT x, and recover c=S_C^-e(x_C). Generate the target word's
coefficient from c, the current target pair labels and the public slot
number. Apply it to the record at that same x. Therefore the scalar
list is recomputed in its actual post-shuffle order, not transported as
an assumed aligned old list. Section I pays its generation in full.

Each completed K_T=H_T tensor I_C preserves every physical control
coordinate. Its eight inner all-axis H calls use STATIC diagonals
depending only on T and local endpoints. Outer controlled scalars are
never read inside that implementation. This establishes the invariant
at the next scalar boundary even though C may move inside K_T.

At every odd-start sublayer translate ALL axes in the fixed target set T,
independently of c and switch settings. Use K_i(c)=I on idle axes/fibers;
their conjugating translations cancel. Thus the flat offset and product
source mask are c-independent. During the flat approximation, bad
records can temporarily carry into C; finish the exact sparse repair
BEFORE decoding any c-dependent setting. Completed translations preserve
x_C. For
a full S^epsilon slot, target wiring advances by that exact permutation
and physical C moves from q_e(c) to q_(e+epsilon)(c). Update e accordingly.
This proves the invariant inductively across every outer slot, including
interleaved target/control axes. On unwind e returns to zero. The result
is exactly the controlled tensor and C is restored on arbitrary inputs.

IV. Finite tape families, scratch lifetimes and crop rules
---------------------------------------------------------
Sparse correction has an explicit key/movement contract. If P=T on
good sources G, then H=P(B)=T(B) for B=complement(G). At bad output
y in H the destination key is T(P^-1(y)); sort those keys and refill
H in increasing order. The sorted destinations ARE the hole list, so
there is no full-key comparison at every good record. Fixed-tape stable
binary radix passes, with staging and zero/one bucket concatenation,
cost O(K b(D+b)) for K bad records and b-bit keys. Add O(K C_addr)
key computation and O(MD) marking/refill. This is correction overhead,
not a linear-cost assertion for the underlying P.

Flat selective shifts use C_addr=O(L^2), K<=M/L^2 and a rotated
product mask to mark H, giving O(V) even D=1. Native weighted XORs
use quotient invariance H=B, direct output marking and the already
retained R_op>=L^64 to pay polynomial metadata. Their tile repair
belongs after one complete eight-update XOR. Its bad marker is
valid_X AND valid_W AND [some quotient margin fails]. Both private
binary bank tails are fixed agreement states, not bad records. Keep
them through repair, use destination ordinals in that same padded
layout, refill only the marked native bad slots, then crop the tails.
The padding factor is below four, but K<=delta M_native before it.
Validity follows the logical target into the dock, not its old slot.

The calling DAG has only the following distinct families; recursive
depth changes their stack lengths, never the tape count.

  host I/O and retained input/product streams;
  classical integer SS and carry-free binary-word arithmetic;
  coefficient CRT/ring arithmetic and its public constant archive;
  tree/route metadata generator and one-record scalar parking;
  tensor-permutation coordinator and sparse-wrap radix sorting;
  native endpoint/H2 role recursion with its role and descriptor stacks;
  weighted tile/rectangle coordinator;
  equal-chunk SWAP recursion with its fixed role and descriptor stacks.

Give these eight families disjoint fixed tape sets. Within one family
reuse its work tapes and park only the CURRENT caller state on that
family's stack. The SWAP proof explicitly restores its work heads and
cleans only visited intervals; its descendants never traverse parked
ancestors. The H2 role protocol has the same current-parent rule with
its own stacks. A tile invocation can call SWAP, but not H2; an H2
invocation can call a tile, but never the CRT coordinator. The metadata
generator uses ordinary sequential integer/table algorithms, not the
new full-array multiplier. The small SS machine is independent.
Thus no recursive cross-family cycle retains unbounded tape families.
Their total is one fixed finite number, however large the finite motif.

The top coordinators call child slots sequentially, with no live scan
head that must be advanced across the outer array at each inner step.
A nested SWAP or H2 call receives the actual array and an ordinary
descriptor; its O(V f(L)) cost already includes passing/restoring it.
The coordinator's work per boundary is a fixed number of O(V) scans
or polynomial-size metadata operations. Outer input streams can remain
parked untouched; they are read when that input's transform is called,
not on each descendant slot. Sum slot costs, not a free circuit-gate
cost and not an additional uncounted ancestor scan.
