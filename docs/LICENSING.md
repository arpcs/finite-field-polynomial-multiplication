# Licensing scope

The first GitHub release uses **Apache-2.0** for original project manuscript,
proof, documentation and code contributions, except files carrying different
source-specific terms. The full canonical text is in [LICENSE](../LICENSE)
and [LICENSES/Apache-2.0.txt](../LICENSES/Apache-2.0.txt).

This follows the single-license approach used by the
[OpenAI math repository](https://github.com/openai/math/blob/main/LICENSE)
and [CrocSwap project](https://github.com/CrocSwap/integer-mult-bounds/blob/main/LICENSE).
The license permits reuse and adaptation subject to its terms, including
retaining required notices and identifying changes. It covers only rights
the relevant contributors can grant and does not replace third-party terms.

Read [NOTICE](../NOTICE) and [third-party notices](THIRD_PARTY_NOTICES.md).
An upstream license reference is not a blanket relicensing of its source.
No separate contributor agreement or transfer of ownership is requested.

The MIT text in `LICENSES/` is a reference copy for the named upstream
dependency, not the default project license. Attribution to a source theorem
does not imply its authors endorse this release.

The arXiv submission license is a separate interface selection at submission
time; Apache-2.0 is not one of arXiv's listed submission options. Preserve
existing reuse grants and choose the appropriate arXiv agreement when an
actual submission is made. See [arXiv license guidance](https://info.arxiv.org/help/license/index.html).
